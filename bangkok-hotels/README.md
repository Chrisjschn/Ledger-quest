# Bangkok FHR / Hotel Collection tracker

A single-page web app for one trip: Bangkok, 1–6 May 2027, two adults. It shows every hotel in
American Express **Fine Hotels + Resorts** and **The Hotel Collection** on a map with photos, keeps
a price log per hotel, and plans how to spread the five nights across four $300 Platinum hotel credits.

Work in progress — the full README is written once the app lands.
